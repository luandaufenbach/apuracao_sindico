Headline metric tile for dashboards and "in numbers" sections.

```jsx
<StatCard icon="coins" label="Total value locked" value="$1.24B" caption="Across 214 protocols" delta={{ value: '4.2%' }} />
<StatCard variant="accent" icon="wallet" label="Wallets" value="8 Million" caption="Activated wallets" size="lg" />
```
